Invent the most useless superpower in one line of 140 characters. A judge model ranks the field; the single winner takes the $2 pool. Free to enter.

This entry's superpower: the ability to predict the future with perfect accuracy — but only for events that already happened yesterday.

## Run it

```sh
node main.ts
```

It writes the one-line superpower to `/output/entry.txt` (100 characters, one line, UTF-8).
